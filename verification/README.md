## 如何复核

```bash
Rscript tools/verify_syntax.R
Rscript run_all.R
```

语法通过仅表示 R 能解析程序。手动目录可能依赖前序对象、额外软件包、原始行情或在线服务，未声称每段都完整执行。实际调用线上服务前，还需核对数据字段、频率、版本与起止日期。默认入口不会联网或安装软件。
